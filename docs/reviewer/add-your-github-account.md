# Add Your GitHub Account

**Type:** Course-level prerequisite · **Tag:** none · **Status: incomplete (0/1)**

## What this is

The bridge between the platform and the repository. The lesson asks the candidate
to open the profile menu, choose *Profile*, scroll to the **Git Account** field,
enter the GitHub username only, and save — then mark the lesson complete so
instructors can find the repository.

## Why it matters to a reviewer

Without it, a reviewer holding a tag link knows the tags but not which account owns
them. The username is the join key between submission and candidate.

This step is still marked **0 / 1** on the course, so treat tag links as unverified
against identity until it is filled. Note the field takes a username, not a URL:
`Natsurii`, not `https://github.com/Natsurii`.

## What a reviewer should look at

1. Confirm the profile's Git Account field is non-empty and matches the owner of
   the repository the tags live in.
2. Confirm the repository is public — a private repository cannot be reviewed from
   a tag link.

## Why it has no tag

It is profile metadata, not code.
