# Final Assessment

**Type:** Course-level · **Tag:** none

## What this is

The course-level assessment page, marked as a prerequisite. It sits after the
GitHub account lesson and before Course End, and is not tied to a single module.

It is not a tagged assignment, so there is no tag to review. It is listed here so
the review trail is complete.

## What a reviewer should look at

The assessment is closed-book in the sense that it does not read the repository; it
tests the candidate, not the code. A reviewer's concern is only that the course is
completed in order, which the platform tracks.

## Why it has no tag

Tags identify code states per assignment. An assessment produces no code.
